# CPUステータス
## 概要
　CPUステータスとは、現在のCPU実行状態を表す値です。HLT命令でCPUの実行が止まった場合、各種例外によってCPUの実行が止まった場合等に点灯します。

　CPUステータスは16bitの値であり、各ビットの意味は次の通りです。点灯時の意味を記載しています。

|bit|意味|
|:--:|:--:|
[0]|CPUへのクロック供給が停止しているときに点灯します。
[1]|ユーザーモードにあるプログラムがカーネルモードでしか実行できない命令を実行しようとした場合に点灯します。
[2]|ユーザーモードにあるプログラムがOS領域や割り込みハンドラ領域等（正確には0x5600番地より小さいメモリアドレスの領域）にアクセスしようとした場合に点灯します。
[3]|未定義命令を実行しようとした場合に点灯します。
[16:4]|未使用
