# 起動シーケンス
　RESET信号投入後、NC-16は以下の手順を踏んで、所定のプログラムを読み込み起動します。

1. メモリ番地0x0000にBIOS_ROMに格納されているプログラム（以下単にBIOSと呼称する）をロードします。読み込むプログラムの大きさは、回路中の定数であるBIOS_SIZEによって指定します。
2. ロード完了後BIOSを実行します。ここまでの手順はハードウェアロジックにより自動的に実行されるようになっています。
3. BIOSはOSプログラムの読み込みを行います。OSプログラムは外部のROMに格納されています。OSプログラムはメモリ番地0x0300に読み込まれます。
4. 読み込んだOSプログラムにジャンプし、OSを起動します。

# OSプログラムバイナリフォーマット
　OSプログラムのバイナリは、OSプログラム本体の先頭に先頭6バイトのヘッダを付けたものです。ヘッダのフォーマットは次の通りです。
1. 4バイト；本プログラムがNC-16対応のOSプログラムであることを示す識別子。識別子の内容は0x2421,0x8f2aである。
2. 2バイト：OSプログラムの大きさを示す値。プログラムサイズバイト数を2で割った値。

　ヘッダが付与されない場合、BIOSはOSプログラムと認識しないか、正常に読み込みが行われません。
