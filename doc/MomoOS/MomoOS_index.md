# MomoOSとは何か
　MomoOSとはNC-16上で動作するオペレーティングシステムです！　ユーザーインタフェースはCUIとなっています。コマンドを打つことで各種命令を実行できます。
　NC-16起動後、``Ready for command.``と表示されたらコマンドを入力できる状態です。MomoOSで使用できるコマンドは以下の通りです。

|コマンド|説明|
|:--:|:--:|
|help|コマンドのヘルプを表示します|
|load romX|romXからメモリ上にプログラムをロードします。Xには1～3までの数字が入ります|
|run|メモリ上に読み込まれたプログラムを実行します
