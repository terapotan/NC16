# 割り込み仕様書
　本ドキュメントではNC-16の割り込み機能について解説します。

## NC-16における割り込み
　割り込みとは、外部からの通知信号によって、実行中の処理を中断し別の処理を実行する仕組みです。NC-16ではINTピンを1にするとNC-16に割り込みが発生したことを通知できます。

　INTピンだけでは、NC-16はどの機器から割り込みが発生したのか認識できません。どの機器から割り込みが発生したのか通知するには、INTピンを1にすると同時に、INT_NUMピンに割り込み番号を入力する必要があります。割り込み番号とは、割り込み原因ごとに割り当てられた番号のことです。

　INTピン、INT_NUMピンは、最低でも、CLKに入力したクロック信号における1クロック以上入力し続ける必要があります。FLAGSレジスタ、INT_NUMレジスタに値を取り込む必要があるためです。

## 割り込み発生時の処理
　NC-16は割り込み発生時次の処理を実行します。以下で示すコードはすべて疑似コードです。
1. MORに0xFF7を代入する
2. INTNUMレジスタにINTNUM and MORの演算結果を代入する（割り込み通知フラグを0にする）
3. MORに0x5000を代入する
4. INTNUMレジスタにMORを加算する
5. 現在のPCレジスタの値をスタックに退避させる
   1. PCレジスタの値をmemvalレジスタに移動
   2. MORに0x0001を代入
   3. spレジスタの値から1を引く
   4. memaddrレジスタにspレジスタの値を移動
   5. MORに0x0000を代入する
   6. メモリのmemaddr番地にmemvalレジスタの値を転送
6. memaddrレジスタにINTNUMレジスタの値を移動
7. memvalレジスタにmemaddrレジスタ番地の値を転送
8. jmp memvalを実行

## 割り込みハンドラの登録
　割り込み番号Aの割り込みハンドラのアドレスは0x5000番地+Aの番地に格納する必要があります。例えば割り込み番号3の割り込みハンドラのアドレスは、0x5003番地に格納する必要があります。割り込み番号3の割り込みが発生したとき、NC-16は0x5003番地に格納されているアドレスにジャンプして命令を実行します。

　割り込みハンドラは、割り込みハンドラを開始する前のレジスタの値を保持する責務を負います。予めレジスタの値をpushしておくなどして、割り込みハンドラ呼び出し前後でレジスタの値が変化しないようにしてください。

　**FLAGSレジスタの保持は忘れやすいため注意してください。**FLAGSレジスタの保持は、演算命令でCarry,Zero,Signフラグの値が変わる前に行う必要があります。
