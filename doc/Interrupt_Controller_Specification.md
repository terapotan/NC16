# 割り込みコントローラ仕様
　回路中、int_controllerと表示されているものが割り込みコントローラです。NC-16には割り込み通知ピンは一つしかありません。ですが、複数の機器からの割り込み要求に対応しなければなりません。複数機器からの割り込み要求を調停し、一つの割り込み要求にまとめる役割を割り込みコントローラは負っています。

各ピンの役割は次の通りです。
- int_0～int_31：各機器の割り込み通知ピンを接続します。同時に複数のピンから割り込み通知が発生した場合は、割り込み番号が最も大きいピンが優先されます。例えばint_2,int_6,int_7の三つから同時に割り込み通知が来た場合は、int_7の割り込みが優先されます。
- INT：NC-16のINTピンに直結させてください。
- out_intnum：NC-16のINT_NUMピンに接続させてください。
